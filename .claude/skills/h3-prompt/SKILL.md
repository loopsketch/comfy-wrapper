# MiniMax H3 のプロンプトを書く

H3 は**形式の決まったプロンプト**で学習している。書式を外すと訓練時と違う形の入力に
なり、カメラ指示・口の動き・音の指定が効かなくなる。ここはその書式に沿って本文を
組み立てるためのスキル。

生成そのものの回し方(ランタイムの確保・停止・課金)は
[colab-comfy](../colab-comfy/SKILL.md) が持っている。**プロンプトを詰めるのはここで
終わらせる。書き直しは無料、生成のやり直しは GPU 時間を使う。**

## 参照ドキュメント

- [references/notation.md](references/notation.md) — 全タスク共通の記法
  (ショット、カメラ語彙表、話者・台詞・歌唱、画面内テキスト、音の2フィールド)
- [references/tasks.md](references/tasks.md) — T2VA / I2VA / FL2VA / L2VA の
  整合指示とコアフィールド、キーフレームの扱い、公式例
- [references/ref2va.md](references/ref2va.md) — 参照モードの6セクション、
  `<Subject N>` `<Picture N>` `<Video N>` `<Audio N>`、保持関係マーカー
- [references/examples.md](references/examples.md) — 書き分けの例

## 手順

### 1. タスク種別を決める

渡す素材から一意に決まる。API 側の指定もここで決まる。

| 渡す素材 | 記法上のタスク | `POST /v1/generate` |
|---|---|---|
| なし | T2VA | `task: "t2v"` |
| 先頭フレーム | I2VA | `task: "i2v"` + `first_frame` |
| 先頭 + 末尾フレーム | FL2VA | `task: "i2v"` + `first_frame` + `last_frame` |
| 参照画像・動画・音声 | Ref2VA | `task: "r2v"` + `ref_images` / `ref_videos` / `ref_audios`(最大 9 / 3 / 3) |
| 末尾フレームだけ | L2VA | **経路なし**(API は `first_frame` 無しの `last_frame` を受けない) |

- 先頭フレームから動かすだけなら I2VA。**キャラの見た目を固定したい、歌唱に
  音声を合わせたいなら Ref2VA。**
- **`r2v` は `minimax-h3` だけ。** Wan / LTX には参照つき生成が無い。
- Ref2VA は `ref2va` のウェイト(+21GB)が要る。構築時に
  `--models "fl2va ref2va"` を指定していないと動かない。

### 2. 生成尺を確定する

H3 は 24fps・**17k+5 フレーム**のグリッドに切り上げ、124〜362 フレームに収める。
`duration` に何を渡してもこの表のどれかになるので、**プロンプト内のタイムスタンプは
生成尺基準**で書く。

| フレーム | 秒 | | フレーム | 秒 |
|---|---|---|---|---|
| 124 | 5.167 | | 243 | 10.125 |
| 141 | 5.875 | | 260 | 10.833 |
| 158 | 6.583 | | 277 | 11.542 |
| 175 | 7.292 | | 294 | 12.250 |
| 192 | 8.000 | | 311 | 12.958 |
| 209 | 8.708 | | 328 | 13.667 |
| 226 | 9.417 | | 345 | 14.375 |
|  |  | | 362 | 15.083 |

5秒未満を頼まれても 5.167 秒生成される。**後ろを切って使う前提なら、切られる側に
見せ場を置かない。**

### 3. 演出を設計する

日本語の意図を H3 の語彙へ翻訳する。決めるのは4つ。

- **カメラ**: 種別・振幅・速度の3次元([notation.md](references/notation.md) の表)。
  「寄り」は `pushes in`(カメラが前進)か `zooms in`(レンズだけ)かまで決める。
  中程度の振幅・通常速度は書かない。
- **時間配分**: 尺の中で何秒目に何が起きるか。動作の開始・変化・着地を並べる。
- **台詞・歌詞**: `<d>[Japanese] ...</d>` に**原文のまま**入れる。翻訳も要約もしない。
- **音**: 環境音・動作音(`overall_soundscape`)と、登場人物に聞こえない音楽
  (`non_diegetic_music`)を分ける。

### 4. 本文を書く

書式は参照ドキュメントに厳密に従う。保存先は `works/prompts/<名前>.txt` で、
**H3 に渡す本文そのもの**を置く(前後に何も足さない)。`works/` は git 管理外。

複数カットを頼まれたときは、**まず1本書いて見せる**。語彙と密度の方針が合っている
ことを確認してから残りへ広げる。

### 5. セルフチェック

下の表で検算する。1つでも外れていたら直してから提示する。

### 6. 生成する

プロンプトはファイルの中身をそのまま `prompt` に入れる。整形も要約もしない。

```bash
docker compose run --rm client -c "
import sys, json, base64; sys.path.insert(0, '/app/src')
from lib import colab_link
endpoint, key = colab_link.read_endpoint(), colab_link.require_api_key()
prompt = open('works/prompts/cut01.txt').read()
still = base64.b64encode(open('works/still.png','rb').read()).decode()
status, body = colab_link.request(endpoint, key, 'POST', '/v1/generate', {
    'model': 'minimax-h3', 'task': 'i2v', 'prompt': prompt,
    'first_frame': still, 'duration': 5.17, 'aspect': '9x16',
})
print(json.loads(body)['job_id'])
"
```

**生成の前にユーザーの承認を取る**(課金対象)。ランタイムの確保・停止は
[colab-comfy](../colab-comfy/SKILL.md) の手順に従う。生成後は必ず結果を見て、
崩れがあればプロンプト側で直す。

## 書くときの原則

- **ムード語を書かない。** `non_diegetic_music` は編成・速度・リズム・強弱だけ。
  「切ない」「エモい」「疾走感」は書かない。
- **negative を混ぜない。** `Avoid: ...` のような行を末尾に足すと形式が崩れる。
  除外したい要素は「何が写っているか」を肯定形で書き切って潰す。
  (`negative` フィールドは Wan / LTX 用で、H3 は使わない)
- **音を手抜きしない。** 最終的に音を差し替えるつもりでも、H3 は映像と音声を同時に
  生成するモデルなので、音の記述は口の動き・動作のタイミング・リズムとして
  **映像側に出る**。
- **実在のブランド名・キャラクター名は書かない。** 見た目を言葉で記述する。
- **本文は英語。** 原文の言語を保つのは `<d>` の中の台詞・歌詞と、画面に実際に
  写っている文字だけ。

## セルフチェック

| 観点 | 見るところ |
|---|---|
| 形式 | 整合指示が1行目にあり、空行1つを挟んでコアフィールドが続く。T2VA には整合指示が無い |
| フィールド | 三つ(参照モードは六つ)が過不足なく、規定の順で並んでいる |
| 尺 | `S.SS` と全タイムスタンプが生成尺の内側。時刻が厳密に増加している |
| ショット | `[Shot 1]` にタイムスタンプが無い。2本目以降に必ずある |
| カット | 各カットが被写体・空間・状態・視点・時間のどれかで新情報を持ち込んでいる。距離やわずかな角度だけの変化ならカメラワークに直す |
| カメラ | 種別が語彙表の値。文末にラベルを積まず、英文として書けている |
| 話者 | 声を出す被写体だけに `(Sx)`。ショットをまたいでIDが一貫。初出で同一性が立つ |
| `<d>` | 中身は言語タグ + 原文のみ。話者名・話し方・動作が中に混入していない。歌詞が原文のまま |
| 参照番号 | `<Picture N>` の番号が、`ref_images` に渡す配列の順番と一致している |
| 参照の役割 | キャラ・小物のシートは `<Subject N>` の中で引用。独立行にしているのは先頭フレームなど具体フレームだけ |
| 露出 | 先頭フレームを渡すカットで、明るさ・光の向き・時刻の保持と「フェードしない」を書いた |
| 音 | `overall_soundscape` に台詞・歌唱・劇中音楽が混入していない。`non_diegetic_music` にムード語が無い |
| 空間 | カメラ位置と被写体の位置関係に矛盾が無い(例: 見上げる視点と言いながら見下ろしている) |

## 完了条件

- `works/prompts/<名前>.txt` に本文がある(H3 に渡す形そのもの)
- セルフチェックを通っている
- ユーザーが内容を承認している(生成の実行はこの後)
